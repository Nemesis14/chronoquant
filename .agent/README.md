# Shared Agent Knowledge

Shared rules for AI agents working on ChronoQuant.

## Files

- `general_agent_principles.md`: behavior that applies to every agent.
- `board_workflow.md`: board and plan lifecycle rules.
- `coding_standards.md`: shared code style and implementation standards.
- `documentation_standards.md`: shared documentation standards.
- `permission_rules.md`: permission authority and expected project capability rules.
- `mcp_rules.md`: MCP and tool-use rules.
- `ai_tools_setup.md`: tool setup and operational notes.

Runtime files such as `.mcp.json`, `settings.json`, and `settings.local.json`
are stored here as shared reference/configuration files. Individual tools may
still require their own launch-time configuration outside this repository.
