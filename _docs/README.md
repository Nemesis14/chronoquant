# _docs — Module Documentation

Mirrors the `src/` directory structure. Each subdirectory contains `.md` files
documenting the corresponding `src/` module.

See `.agent/skills/docs_skill.md` for conventions and the doc file template.

---

## Structure

```
_docs/
  store/             ← src/store/
  data_pipeline/     ← src/data_pipeline/
  modeling/          ← src/modeling/
  evaluation/        ← src/evaluation/
  streamlit_app/     ← src/streamlit_app/
  trading/           ← src/trading/
  app/               ← src/app/
  elliott_waves/     ← src/elliott_waves/
  plotting/          ← src/plotting/
```
