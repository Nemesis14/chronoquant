# Backlog

Implementacios specifikaciok es jovobeli fejlesztesi tervek.

---

## Szabalyok

- A konkret fejlesztesi specifikaciok ide kerulnek, nem a `docs/` ala.
- Egy spec fajl neve legyen rovid es temahoz kotott, pelda:
  `prediction_long_short_schema.md`.
- Ha egy backlog spec aktiv fejlesztesbe kerul, a `board.md` hivatkozzon ra.
