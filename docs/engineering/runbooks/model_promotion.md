# Runbook: Model Promotion

Use this checklist after model validation and strategy evaluation are complete.

1. Confirm model card is complete.
2. Confirm holdout result is documented.
3. Confirm strategy report and selected thresholds are documented.
4. Update `config/models.json`.
5. Update `config/env.json`.
6. Update `config/strategies.json`.
7. Sync a bounded prediction window.
8. Verify dashboard config.
9. Run focused tests.

Detailed model workflow: `docs/modeling/lightgbm_development.md`.
